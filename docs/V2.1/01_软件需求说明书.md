# RM SuperCap Controller 软件需求说明书 V2.1

## 1. 文档目的

本文档定义 RM SuperCap Controller 软件 V2.1 的正式需求，作为后续软件设计、编码、调试和测试依据。

V2.1 是在 V2.0 基础上的冻结版本，重点重构内容包括：

- 状态机由单一 SystemState 重构为 `SystemState + RunMode`。
- 删除 INIT / SELF_CHECK / IDLE / SOFT_START_CHARGE / SOFT_START_DISCHARGE。
- CHARGE / DISCHARGE 不再作为 SystemState，而作为 RUNNING 下的 RunMode。
- 功率方向由功率迟滞比较器直接切换。
- 充放电切换不进入 IDLE，不主动停止 PWM，不使用软启动。
- Power PI 输出单位冻结为 W。
- FSBB 调制冻结为电压前馈 `Dg_base` 与电流环 PI 输出 `Dg_comp` 叠加。
- Fault 需求冻结。

## 20. V2.1 冻结结论

V2.1 已冻结以下核心需求：

- 新状态机：`SystemState + RunMode`。
- Fault 逻辑。
- CAP_OV 事件计数规则。
- 功率方向迟滞比较器。
- Power PI 输出 W。
- 充电电流参考换算。
- 放电总电流参考与两相分配。
- FSBB 电压前馈 + PI 补偿叠加。
- Dg_comp / Dg_cmd 限幅。
- 三模态 FSBB 映射。
- PWM 频率、死区和自举刷新基本策略。
- ADC 基础换算参数。
- CAN 基础协议。
