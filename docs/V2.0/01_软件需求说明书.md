# RM SuperCap Controller 软件需求说明书 V2.0

## 1. 文档目的

本文档定义 RM SuperCap Controller 软件 V2.0 的功能需求、控制需求、状态机需求、故障管理需求、PWM/HRTIM 需求、ADC 参数需求和 CAN 通信需求。

本文档作为后续软件设计、编码、调试和测试的依据。

---

## 2. 项目目标

本项目用于实现基于 STM32G474 的 RoboMaster 超级电容控制器软件。

系统包含：

- 一路四开关 Buck-Boost 充电通道
- 两路四开关 Buck-Boost 并联放电通道
- 放电两相固定 180° 错相 PWM
- CAN 控制与状态上报
- 故障检测与保护

软件需要实现：

- 功率管理
- 充电控制
- 放电控制
- 状态机管理
- Fault 管理
- ADC 采样换算
- PWM/HRTIM 输出
- CAN 通信

---

## 3. 系统输入

### 3.1 CAN 输入

主控通过 CAN 下发：

- enable
- clear_fault
- power_limit

power_limit 参数：

| 参数 | 数值 |
|---|---:|
| 默认值 | 50W |
| 最大值 | 120W |
| 单位 | W |
| 超出处理 | 钳位到 120W |

CAN enable 仅表示工作请求，不能绕过 Fault。

clear_fault 仅用于清除已经消失的锁死故障。如果当前故障条件仍然存在，则 clear_fault 无效。

CAN 超时不作为故障源。

### 3.2 ADC 输入

软件采样：

- V_bat
- V_cap
- V_chassis
- I_bat
- I_charge
- I_chassis
- I_phase_a
- I_phase_b
- I_discharge_total

并计算：

```text
P_input = V_bat * I_bat
P_chassis = V_chassis * I_chassis
```

---

## 4. 功率管理需求

本版本不接入裁判系统缓存能量，不使用 ENERGY_BUFFER / energyRemain。

仅使用：

- power_limit
- P_input
- P_chassis

V2.0 中，充电方向使用功率余量生成充电电流参考；放电方向使用输入功率环控制 P_input 接近 power_limit。

---

## 5. 充电控制需求

充电进入条件：

```text
系统无故障
P_chassis < power_limit
```

充电采用：

```text
功率余量
↓
恒功率计算
↓
输入电流参考
↓
输出电流限制
↓
30V 电压 PI 限流
↓
输入电流 PI
↓
FSBB 广义占空比调制
↓
PWM
```

充电功率：

```text
P_charge_target = power_limit - P_chassis
P_charge_limit = min(P_charge_target, 120W, V_cap * 10A)
I_charge_ref = P_charge_limit / V_input
```

30V 是充电控制目标，不是 Fault。

---

## 6. 放电控制需求

放电进入条件：

```text
P_input > power_limit + 5W
V_cap > 8V
low_cap_lock = false
系统无故障
```

放电退出条件：

```text
P_input < power_limit - 5W
```

功率迟滞：

```text
P_hys = 5W
```

放电控制目标：

```text
通过输入功率环控制 P_input 接近 power_limit
```

最大放电功率：

```text
P_discharge_max = 500W
```

放电总电流限制：

```text
I_discharge_total_limit = 500W / V_chassis
I_phase_ref = I_discharge_total_ref / 2
```

两相固定 180° 错相，前期依靠两相独立电流环自然均流。

---

## 7. 电容电压管理需求

| 条件 | 处理 |
|---|---|
| V_cap <= 8V | 非故障，禁止放电，进入低压充电锁定 |
| V_cap >= 10V | 解除低压锁定 |
| V_cap = 30V | 充电控制目标，由电压 PI 限流 |
| V_cap > 31V | 电容过压恢复 |
| V_cap <= 28V | 允许重新软启动充电 |

低压锁定：

```text
V_cap <= 8V  -> low_cap_lock = true
V_cap >= 10V -> low_cap_lock = false
```


## 9. Fault 管理需求

Fault 分为：

- FAULT_RECOVERABLE
- CAP_OV_RECOVER
- FAULT_LATCHED

### 9.1 可恢复故障

输入欠压：

```text
V_input < 22V
```

恢复：

```text
V_input > 23V 且持续 500ms
```

轻度过流：

```text
实际电流 > 动态限值 * 110%
持续 10ms
```

### 9.2 电容过压恢复

触发：

```text
V_cap > 31V
```

动作：

```text
关闭充电 PWM
清充电电流 PI
清电压 PI
cap_ov_count++
进入 CAP_OV_RECOVER
```

恢复：

```text
V_cap <= 28V
CAN enable 有效
-> SOFT_START_CHARGE
```

如果：

```text
cap_ov_count >= 3
```

进入 FAULT_LATCHED。

### 9.3 锁死故障

包含：

```text
V_input < 20V
V_input > 28V
严重过流
cap_ov_count >= 3
```

严重过流：

```text
实际电流 > 动态限值 * 120%
持续 2ms
```

FAULT_LATCHED 不允许自动恢复，只能通过 clear_fault 清除，且当前故障条件必须已经消失。

## 10. ADC 参数需求

ADC 参数：

| 参数 | 数值 |
|---|---:|
| ADC 参考电压 | 3.0V |
| ADC 位数 | 12bit |
| 电流零点 | 1.65V |
| INA240A1 增益 | 20V/V |

电压换算：

```text
V_adc = adc_raw * 3.0 / 4095
V_real = V_adc * 10
```

电流换算：

```text
I = abs((V_adc - 1.65) / (Rshunt * 20))
```

采样电阻：

| 信号 | Rshunt |
|---|---:|
| I_bat | 5mΩ |
| I_charge | 5mΩ |
| I_chassis | 2mΩ |
| I_phase_a | 2mΩ |
| I_phase_b | 2mΩ |

Average Current 未经过二级运放增益，换算方式与相电流一致。

## 11. PWM / HRTIM 需求

PWM 频率：

| 通道 | 频率 |
|---|---:|
| 充电 FSBB | 100kHz |
| 放电 Phase A | 300kHz |
| 放电 Phase B | 300kHz |

参数：

| 参数 | 数值 |
|---|---:|
| 死区时间 | 50ns |
| 占空比范围 | 0% ~ 100% |
| Fault 输出 | 所有 PWM 拉低 |

放电两相固定 180° 错相。

---

## 12. 广义占空比调制需求

FSBB 采用广义占空比思想。

广义占空比：

```text
Dg = Vout / Vin
```

模式判断：

```text
Dg < 0.8      -> Buck
Dg > 1.25     -> Boost
0.8~1.25      -> Buck-Boost
```

映射：

Buck：

```text
D_input  = 1.0
D_output = Dg
```

Boost：

```text
D_input  = 1.0 / Dg
D_output = 1.0
```

Buck-Boost：

```text
D_input  = (Dg + 1.0) * 0.4
D_output = (1.0 / Dg + 1.0) * 0.4
```

---

## 13. Bootstrap 自举刷新需求

当桥臂占空比为 100% 时，底层 PWM 执行自举刷新。

Buck 模式：输入桥臂 100%，输入桥臂刷新。

Boost 模式：输出桥臂 100%，输出桥臂刷新。

Buck-Boost 模式：两个桥臂均参与 PWM，不额外刷新。

刷新参数：

```text
默认每 10 个 PWM 周期刷新一次
默认刷新宽度 1 个 PWM 周期
```

通过宏定义配置。

---

## 14. 控制频率需求

充电：

```text
PWM：100kHz
电流环：100kHz
功率环：1kHz
电压环：1kHz
```

状态机建议 1kHz。CAN 上报建议 10ms。

---

## 15. CAN 协议需求

采用一收一发。

RX：主控到超级电容，CAN ID 0x301，DLC 8。

| Byte | 内容 |
|---|---|
| Byte0 bit0 | enable |
| Byte0 bit1 | clear_fault |
| Byte1 | power_limit，单位 W |
| Byte2~7 | 保留 |

TX：超级电容到主控，CAN ID 0x302，DLC 8。

| Byte | 内容 |
|---|---|
| Byte0 | system_state |
| Byte1 | fault_code |
| Byte2 | V_cap，单位 0.2V |
| Byte3 | power_limit，单位 W |
| Byte4~5 | P_input，单位 0.1W，小端 |
| Byte6~7 | P_chassis，单位 0.1W，小端 |

---

## 16. Soft Start 需求

软启动不直接爬 PWM 占空比，而是爬电流参考。

从故障恢复后必须重新软启动。
