# RM SuperCap Controller 软件设计说明书 V2.0

## 1. 文档目的

本文档基于《RM SuperCap Controller 软件需求说明书 V2.0》，给出软件模块划分、状态机设计、控制链路设计、Fault 处理、ADC 换算、PWM/HRTIM 调制和 CAN 通信实现方案。

V2.0 属于第一版完整软件架构设计，保留 INIT、SELF_CHECK、IDLE、SOFT_START_CHARGE、SOFT_START_DISCHARGE 等状态。

---

## 2. 软件总体架构

软件采用分层模块结构：

```text
Application Layer
├── SuperCapApp
├── StateMachine
├── FaultManager
├── PowerManager
├── ChargeManager
├── DischargeManager
└── CanProtocol

Control Layer
├── PowerPI
├── VoltagePI
├── CurrentPI
└── FsbbModulator

Driver Layer
├── ADC Driver
├── HRTIM PWM Driver
├── CAN Driver
├── GPIO Driver
└── Debug/UART Driver
```

主数据流：

```text
ADC采样
  ↓
ADC换算与滤波
  ↓
功率计算 P_input / P_chassis
  ↓
状态机与Fault判断
  ↓
ChargeManager / DischargeManager
  ↓
PI控制器
  ↓
FSBB广义占空比调制
  ↓
HRTIM PWM输出
```

---

## 3. 主循环与任务设计

V2.0 推荐使用周期任务结构。

```text
100 kHz：充电电流环
100 kHz：放电电流环，每3个300kHz PWM周期执行一次
1 kHz：功率环、电压环、状态机、Fault软件判断
10 ms：CAN状态上报
```

建议任务：

| 任务 | 周期 | 说明 |
|---|---:|---|
| ADC采样回调 | PWM同步 | 采集电压电流 |
| CurrentControlTask | 100 kHz | 电流环控制 |
| SlowControlTask | 1 kHz | 功率环、电压环、状态机、Fault |
| CanTxTask | 10 ms | 状态上报 |
| DebugTask | 可配置 | 调试输出 |

## 4. 状态机设计

V2.0 系统状态：

```c
typedef enum
{
    SYS_DISABLED = 0,
    SYS_INIT,
    SYS_SELF_CHECK,
    SYS_IDLE,
    SYS_SOFT_START_CHARGE,
    SYS_CHARGE,
    SYS_SOFT_START_DISCHARGE,
    SYS_DISCHARGE,
    SYS_CAP_OV_RECOVER,
    SYS_FAULT_RECOVERABLE,
    SYS_FAULT_LATCHED,
} SystemState_t;
```

状态优先级：

```text
CAN disable
FAULT_LATCHED
CAP_OV_RECOVER
FAULT_RECOVERABLE
正常状态机
```

### 4.1 DISABLED

进入条件：

```text
CAN enable = 0
```

动作：

```text
所有PWM关闭
PI积分清零
保持CAN通信
```

### 4.2 INIT

动作：

```text
初始化软件变量
清控制器积分
初始化Fault标志
初始化PWM输出为关闭
```

完成后进入 SELF_CHECK。

### 4.3 SELF_CHECK

检查内容：

```text
ADC电压是否在合理范围
输入电压是否满足启动条件
电容电压是否未严重过压
HRTIM Brake状态是否正常
```

检查通过进入 IDLE；失败进入对应 Fault。

### 4.4 IDLE

IDLE 下不输出功率，等待功率条件选择充电或放电。

```text
P_input > power_limit + 5W 且 V_cap > 8V -> SOFT_START_DISCHARGE
否则如果 P_chassis < power_limit -> SOFT_START_CHARGE
```

### 4.5 SOFT_START_CHARGE

目的：降低充电启动瞬态。

动作：

```text
充电电流参考从0缓慢增加到目标值
充电PWM逐步使能
```

完成后进入 CHARGE。

### 4.6 CHARGE

执行充电控制链路：

```text
功率余量 -> 充电功率限制 -> 输入电流参考 -> 30V电压环限流 -> 电流环 -> FSBB -> PWM
```

若满足放电条件，进入 SOFT_START_DISCHARGE。

### 4.7 SOFT_START_DISCHARGE

目的：降低放电启动冲击。

动作：

```text
放电电流参考从0缓慢增加到目标值
两相PWM按180°错相启动
```

完成后进入 DISCHARGE。

### 4.8 DISCHARGE

执行放电控制链路：

```text
输入功率环 -> 放电总功率参考 -> 总电流参考 -> 两相电流参考 -> 两相电流环 -> FSBB -> PWM
```

若 `P_input < power_limit - 5W`，退出放电并进入 IDLE 或充电软启动。

## 5. 功率管理设计

V2.0 不使用裁判系统能量缓冲。

功率输入：

```text
P_input = V_bat * I_bat
P_chassis = V_chassis * I_chassis
```

充电功率目标：

```text
P_charge_target = power_limit - P_chassis
P_charge_limit = min(P_charge_target, 120W, V_cap * 10A)
```

放电功率目标：

```text
PowerPI控制P_input接近power_limit
P_discharge_ref <= 500W
```

---

## 6. 充电控制设计

充电电流参考：

```text
I_charge_ref_power = P_charge_limit / V_input
```

30V电压环：

```text
V_error = 30V - V_cap
I_charge_cv_limit = VoltagePI(V_error)
```

最终参考：

```text
I_charge_ref = min(I_charge_ref_power, I_charge_cv_limit, I_charge_hw_limit)
```

电流环：

```text
I_error = I_charge_ref - I_charge_ADC
Dg_comp = CurrentPI(I_error)
```

---

## 7. 放电控制设计

放电功率环：

```text
P_error = P_input - power_limit
P_discharge_ref = PowerPI(P_error)
P_discharge_ref = clamp(P_discharge_ref, 0, 500W)
```

总电流参考：

```text
I_discharge_total_ref = P_discharge_ref / V_chassis
I_phase_ref = I_discharge_total_ref / 2
```

两相电流环：

```text
Dg_comp_A = CurrentPI_A(I_phase_ref - average_I_phase1_ADC)
Dg_comp_B = CurrentPI_B(I_phase_ref - average_I_phase2_ADC)
```

两相固定 180° 错相。

## 8. FSBB 广义占空比调制设计

广义占空比：

```text
Dg = Vout / Vin
```

三模态判断：

```text
Dg < 0.8  -> Buck
Dg > 1.25 -> Boost
其余      -> Buck-Boost
```

映射公式：

```text
Buck:
D_input  = 1.0
D_output = Dg

Boost:
D_input  = 1.0 / Dg
D_output = 1.0

Buck-Boost:
D_input  = (Dg + 1.0) * 0.4
D_output = (1.0 / Dg + 1.0) * 0.4
```

控制器输出补偿项可叠加到 Dg 后进入映射器，具体补偿结构在 V2.1 中进一步冻结。

## 9. PWM/HRTIM 设计

频率：

| 通道 | 频率 |
|---|---:|
| 充电FSBB | 100 kHz |
| 放电Phase A | 300 kHz |
| 放电Phase B | 300 kHz |

死区：50 ns。

Fault 时所有 PWM 拉低。

自举刷新：

```text
Buck：输入桥臂100%，刷新输入桥臂
Boost：输出桥臂100%，刷新输出桥臂
Buck-Boost：不额外刷新
```

刷新参数：

```text
每10个PWM周期刷新一次
刷新宽度1个PWM周期
```

## 10. ADC 换算设计

ADC 参考电压 3.0V，12bit。

```c
V_adc = adc_raw * 3.0f / 4095.0f;
```

电压分压 9k:1k：

```c
V_real = V_adc * 10.0f;
```

电流换算：

```c
I = fabsf((V_adc - 1.65f) / (Rshunt * 20.0f));
```

采样电阻：

```text
I_bat      5mΩ
I_charge   5mΩ
I_chassis  2mΩ
I_phase_a  2mΩ
I_phase_b  2mΩ
```

## 11. Fault 设计

Fault 分类：

```c
typedef enum
{
    FAULT_NONE = 0,
    FAULT_RECOVERABLE,
    FAULT_CAP_OV_RECOVER,
    FAULT_LATCHED,
} FaultState_t;
```

可恢复故障：

```text
V_input < 22V
轻度过流：实际电流 > 动态限值 * 110%，持续10ms
```

恢复：

```text
V_input > 23V 且持续500ms
过流条件消失并稳定
```

电容过压恢复：

```text
V_cap > 31V -> CAP_OV_RECOVER
V_cap <= 28V -> SOFT_START_CHARGE
cap_ov_count >= 3 -> FAULT_LATCHED
```

锁死故障：

```text
V_input < 20V
V_input > 28V
严重过流：实际电流 > 动态限值 * 120%，持续2ms
cap_ov_count >= 3
```

锁死故障仅允许在故障条件消失后通过 clear_fault 清除。

## 12. CAN 设计

RX：ID 0x301，DLC 8。

| Byte | 内容 |
|---|---|
| Byte0 bit0 | enable |
| Byte0 bit1 | clear_fault |
| Byte1 | power_limit，W |
| Byte2~7 | reserved |

TX：ID 0x302，DLC 8。

| Byte | 内容 |
|---|---|
| Byte0 | system_state |
| Byte1 | fault_code |
| Byte2 | V_cap，0.2V/bit |
| Byte3 | power_limit，W |
| Byte4~5 | P_input，0.1W/bit，小端 |
| Byte6~7 | P_chassis，0.1W/bit，小端 |

TX周期建议 10ms。

## 13. V2.0 到 V2.1 演进说明

V2.0 保留完整状态机和软启动流程；V2.1 对状态机进行了简化，将 CHARGE/DISCHARGE 从 SystemState 中拆出为 RunMode，并冻结了 FSBB 的电压前馈 + PI补偿结构。

V2.0 文档作为历史设计依据保留。
