#### 目标

实现一个一次性就行正常运行的超级电容控制器的代码框架。

#### 概述

​	硬件使用的stm32G474rbt6，其他的硬件暂时待定，根据docs中的文档，生成一份你举得必要的硬件配置文档，将所有可能得硬件配置都罗列出来，供我填写，后续方便你直接生成文档。

​	软件的话使用frrertos。根据需求生成对应的任务，如果是控制你频率在1Khz以上的，在中断里运行，小于等于1KHZ的，在任务中运行。同时需要注意生成的代码不要在中断里加入任何又可能阻塞的函数或任务，在中断里不能出现又延时函数之类的东西。代码避免不必要的跳转，要求简洁易懂，要求要有对应的注释，要求要能让人能够看懂方便更改。但是也要求能根据模块分文件编写，命名要格式统一，变量名要不易混淆。

​	现在要设计一个三端口的四开关的buck-boost超级电容控制器，用于给超级电容充电和放电，三个端口分别是电源输入口，超级电容接口，机器人底盘接口。

​	电源输入为整个系统供电，但是使用功率限制的，在这里我们称为power_limit。电源的输入能直接为机器人底盘供电，同时也能通过超级电容控制器为超级电容充电。

​	超级电容的接口直接接到超级电容，为超级电容提高充电和放电。

​	底盘接口接到机器人的底盘。当底盘的功率低于power_limit是，多余的功率会被用来给超级电容充电。如果功率高于power_limit时，超级电容就会进入放电模式，电源一起并联为底盘供电。

#### 拓扑

​	本设计的结构和在docs中的超级电容控制器的设计有所不同，在docs中介绍的都是单路buck-boost实现双向的充电放电。本设计是充电和放电独立开来，充电是单独的一路buck-boost，放电使用的是双相并联交错的buck-boost。所以就是说一共有三个buck-boost控制器。由于充电和放电的功率相差比较大，所以这个分开两路的设计能在硬件设计实现效率的最大化。
​	每一路buck--boost的降压、升压、升降压的模式切换也需要设计好，需要你参考docs中的文档，给出详细的方案。如果有多种选择，和我讨论。

​	此外需要注意的是，本设计中的buckboost的上管由于硬件限制，没能完成上管常开，所以只能使用跳脉冲模式。比如在运行buck模式的时候，左边桥臂是一直在运行的，此时右边桥臂的上管就需要常开，但是由于硬件的限制，上管的自举电容会放电，当自举电容上的电压下降到一定程度的时候，上管就会关断，所以就需要下管能周期性地短暂打开为上管的自举电容充电。



#### 功率环

​	功率环控制的是电源的功率不要超过功率限制，这个需要用一个功率pid环路来控制，具体的实现可以参考docs中的实现。再给出方案之后，交给我确认。功率环的输出会被用来判断当前是出于充电状态还是放电状态，还有充放电的功率。

#### 充电

​	充电环路需要考虑的因素有三点，一个是输入的充电功率，一个是电压环，一个是电流环（在本设计中是输入电流环，电流环用来控制在超电电容电压过低的时候电流过高，需要限制充电的电流）。
​	现在需要考虑的是功率环和电压环还有电流环之间的关系。有串联，有并联，还有串并联。现在需要你阅读理解docs中的其他工程的是怎么实现的之，给出详细的方案，和我讨论。


#### 放电

​	在放电模式下。控制相对比较简单，只需要使用一个输出电流环即可。输入为超级电容的输入端口。放电的功率使用功率环的输出功率，然后除以电源电压得到超级电容控制器的输出电流。

​	需要注意的是，放电环路是采用两个buck-boost并联得到的，这两个buck-boost之间的相位180度错开。电流采样有电感平均电流采样和输出电路采样 ，目前比较偏向的是使用电感平均电流采样，如果行不通，就使用输出电流采样。现在需要判断使用电感平均电流采样的风险点。
​	需要补充的是，每一相的电流为总的放电电流/2。每一相都有一个单独的电流环，用来做到每一相的电流能均衡输出。

#### 充电和放电的关系

​	这两个模式尽量不能同时进行，如果切换来不及，也需要规定一个最小的能同时运行的时间。
