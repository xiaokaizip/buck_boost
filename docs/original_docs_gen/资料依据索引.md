## 6. 需求和设计来源

### 6.1 用户原始需求

用户明确提出：

- 使用 STM32G474RBT6。
- 使用 FreeRTOS。
- 高频控制放在中断里。
- 小于等于 1kHz 的任务放在 FreeRTOS task 中。
- 中断内不能有阻塞、延时、打印等操作。
- 代码要模块化、命名统一、便于理解和修改。
- 三端口系统：电源输入口、超级电容口、机器人底盘口。
- 充电和放电硬件独立。
- 充电一路 FSBB。
- 放电两相 FSBB 并联错相。
- 放电两相相位差 180°。
- 放电每相独立电流环。
- 功率环控制电源输入功率不超过 `power_limit`。
- CAN 下发 `power_limit`。
- 增加硬件比较器触发 HRTIM brake。

### 6.2 设计推导依据

本次需求文档中的主要设计推导来自：

- 三端口功率流关系。
- 用户描述的充放电独立拓扑。
- 控制板/功率板原理图采样与 PWM 连接。
- RM2024 报告中的广义占空比和功率控制思想。
- STM32G474 HRTIM / COMP / ADC / FDCAN 外设能力。
- FreeRTOS 中断与任务划分原则。
