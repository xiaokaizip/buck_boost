# RM SuperCap Controller 软件需求说明书 V2.0

## 1. 文档目的

本文档用于定义 RM SuperCap Controller 软件 V2.0 的功能需求、控制需求、状态机需求、故障管理需求、PWM/HRTIM 需求、ADC 参数需求和 CAN 通信需求。

## 2. 项目目标

本项目用于实现基于 STM32G474 的 RoboMaster 超级电容控制器软件。

系统包含：

- 一路四开关 Buck-Boost 充电通道
- 两路四开关 Buck-Boost 并联放电通道
- 放电两相固定 180° 错相 PWM
- CAN 控制与状态上报
- 故障检测与保护

## 3. 功率管理

本版本不接入裁判系统缓存能量，不使用 ENERGY_BUFFER / energyRemain。

仅使用：

- power_limit
- P_input
- P_chassis

power_limit：默认 50W，最大 120W，单位 W，超过 120W 直接钳位。

## 4. 充电控制

充电条件：系统无故障，P_chassis < power_limit。

充电采用恒功率控制、输入电流环、30V 电压 PI 限流。输出充电电流无直接采样，通过功率换算限制为 10A。

```text
P_charge_target = power_limit - P_chassis
P_charge_limit = min(P_charge_target, 120W, V_cap * 10A)
I_charge_ref = P_charge_limit / V_input
```

## 5. 放电控制

放电条件：P_input > power_limit + 5W，V_cap > 8V，系统无故障。

放电退出条件：P_input < power_limit - 5W。

放电最大功率 500W。

```text
I_discharge_total_limit = 500W / V_chassis
I_phase_ref = I_discharge_total_ref / 2
```

两相放电固定 180° 错相，前期依靠两相独立电流环自然均流。

## 6. 电容电压管理

| 条件 | 处理 |
|---|---|
| V_cap <= 8V | 非故障，禁止放电，进入低压充电锁定 |
| V_cap >= 10V | 解除低压锁定 |
| V_cap = 30V | 充电控制目标，由电压 PI 限流 |
| V_cap > 31V | 电容过压恢复 |
| V_cap <= 28V | 允许重新软启动充电 |

## 7. 系统状态机

系统状态：

```text
DISABLED
INIT
SELF_CHECK
IDLE
SOFT_START_CHARGE
CHARGE
SOFT_START_DISCHARGE
DISCHARGE
CAP_OV_RECOVER
FAULT_RECOVERABLE
FAULT_LATCHED
```

状态优先级：CAN disable > FAULT_LATCHED > CAP_OV_RECOVER > FAULT_RECOVERABLE > 正常状态机。

## 8. Fault 管理

Fault 分为：

- FAULT_RECOVERABLE
- CAP_OV_RECOVER
- FAULT_LATCHED

可恢复故障包括输入欠压和轻度过流。

```text
V_input < 22V -> FAULT_RECOVERABLE
V_input > 23V 且持续 500ms -> 恢复
```

锁死故障包括：

```text
V_input < 20V
V_input > 28V
严重过流
cap_ov_count >= 3
```

clear_fault 只能清除已经消失的锁死故障。当前故障条件仍存在时，clear_fault 无效。

## 9. 动态过流保护

过流保护根据功率动态换算。

轻度过流：超过动态限值 10%，持续 10ms，进入 FAULT_RECOVERABLE。

严重过流：超过动态限值 20%，持续 2ms，进入 FAULT_LATCHED。

## 10. ADC 参数

ADC 参考电压 3.0V，12bit。电流零点 1.65V，INA240A1 增益 20V/V。

电压分压比 9k:1k，换算系数 10。

```text
V_adc = adc_raw * 3.0 / 4095
V_real = V_adc * 10
I = abs((V_adc - 1.65) / (Rshunt * 20))
```

采样电阻：I_bat 5mΩ，I_charge 5mΩ，I_chassis 2mΩ，I_phase_a 2mΩ，I_phase_b 2mΩ。

## 11. PWM / HRTIM

| 通道 | 频率 |
|---|---|
| 充电 FSBB | 100kHz |
| 放电 Phase A | 300kHz |
| 放电 Phase B | 300kHz |

死区 50ns，故障时所有 PWM 拉低。放电两相固定 180° 错相。

## 12. CAN 协议

采用一收一发。

RX：主控到超级电容，CAN ID 0x301，DLC 8。

| Byte | 内容 |
|---|---|
| Byte0 bit0 | enable |
| Byte0 bit1 | clear_fault |
| Byte1 | power_limit，单位 W |
| Byte2~7 | 保留 |

TX：超级电容到主控，CAN ID 0x302，DLC 8。

| Byte | 内容 |
|---|---|
| Byte0 | system_state |
| Byte1 | fault_code |
| Byte2 | V_cap，单位 0.2V |
| Byte3 | power_limit，单位 W |
| Byte4~5 | P_input，单位 0.1W，小端 |
| Byte6~7 | P_chassis，单位 0.1W，小端 |
